# 完整流程實作手冊

- 對象：要實際使用系統送簽核的人
- 使用帳號：三個角色輪流登入（見下方）
- 前置：表單與流程已設定並發布
- 截圖來源：`web/e2e/manual-04-endtoend.spec.ts`

本手冊示範**一張報價單從建立到簽核完成的完整過程**。

---

## 1. 這次要走的路

```
王景榮（業務）建立報價單
      ↓ 送簽
陳雅婷（業務主管）簽核
      ↓ 核准
   折扣率判斷
      ↓ 超過 15%，需要財務加簽
李淑芬（財務主管）簽核
      ↓ 核准
      完成
```

三個帳號，公司代碼都是 `demo`，密碼都是 `demo1234`：

| 帳號 | 姓名 | 角色 | 在這個流程做什麼 |
|------|------|------|------------------|
| `sales@demo.local` | 王景榮 | 申請人 | 建立報價單並送簽 |
| `designer@demo.local` | 陳雅婷 | 設計者、業務主管 | 第一關簽核 |
| `finance@demo.local` | 李淑芬 | 財務主管 | 第二關簽核 |

> **為什麼第一關是陳雅婷而不是張文華（cfo）？**
>
> 流程的第一關用「申請人的主管」指派。王景榮的主管是陳雅婷，
> 所以待辦落在她那裡。如果換別人送簽，第一關就會是別人的主管。
>
> 這就是「部門主管」這類指派方式的用意——不必為每個部門各寫一條流程。

## 3. 填寫報價單

### 3.1 表頭

![填寫客戶資料](screenshots/04-端到端/06-填寫客戶資料.png)

| 欄位 | 填什麼 |
|------|--------|
| 報價單號 | 自訂編號，例如 `QT-2026-0042` |
| 客戶名稱 | 台灣松下精密機械股份有限公司 |

### 3.2 折扣率

![填寫折扣率](screenshots/04-端到端/07-填寫折扣率.png)

**折扣率填小數，不是百分比。**

| 想表達 | 要填 | 不要填 |
|--------|------|--------|
| 20% | `0.2` | ~~`20`~~ |
| 15% | `0.15` | ~~`15`~~ |
| 5% | `0.05` | ~~`5`~~ |

填 `20` 會被當成 2000%，送出時會被擋下並顯示「表頭折扣率不得大於 0.5」。

> 這次填 `0.2`（20%），**超過 15% 的門檻**，
> 所以流程會多走一關財務簽核。這正是要示範的分支。

## 4. 填寫明細

按「新增一列」。

![新增明細列](screenshots/04-端到端/08-新增明細列.png)

每一列填七個欄位：

![填寫明細內容](screenshots/04-端到端/09-填寫明細內容.png)

| 欄位 | 範例 | 說明 |
|------|------|------|
| 料號／規格品名 | PA-3021 主軸座 | |
| 圖號／版次 | DWG-3021-C | |
| 材質／熱處理條件 | SCM440 調質 | |
| 數量 | 50 | |
| 單位 | PCS | |
| 單位材料費 | 1850 | **算毛利率用** |
| 單位加工費 | 2400 | **算毛利率用** |
| 單位售價 | 5200 | **算金額用** |

> **金額是用「單位售價」算的，不是材料費加加工費。**
> 材料費與加工費只用來算毛利率。只填成本不填售價的話，
> 小計會是 0 而且送不出去。

再加一列。

![兩列明細](screenshots/04-端到端/10-兩列明細.png)

### 金額自動計算

![金額自動計算](screenshots/04-端到端/11-金額自動計算.png)

系統會自動算出：

| 項目 | 怎麼算 |
|------|--------|
| 小計 | 各列（單價 × 數量）加總，扣掉折扣 |
| 營業稅 5% | 小計 × 0.05 |
| 預估毛利率 | (售價 − 成本) ÷ 售價 |
| 報價總計（含稅） | 小計 + 稅 |

這些欄位是唯讀的，改不了——它們由公式決定。

## 6. 送簽

捲到最下方按「送出」。

![送出前確認](screenshots/04-端到端/13-送出前確認.png)

送出後回到清單，新的報價單出現在最上方。

![送簽完成](screenshots/04-端到端/14-送簽完成.png)

狀態顯示「簽核中」。

> **送出失敗怎麼辦？**
> 畫面會停在原地並顯示紅色錯誤訊息，內容會指出是哪個欄位有問題。
> 常見的是折扣率填成百分比、明細沒填單位售價、客戶聯絡人空白。

![主管登入](screenshots/04-端到端/15-主管登入.png)

### 7.2 處理待辦

![主管收到待辦](screenshots/04-端到端/16-主管收到待辦.png)

每一筆待辦顯示：節點名稱、單號、送來的時間。

![填寫簽核意見](screenshots/04-端到端/17-填寫簽核意見.png)

![主管核准完成](screenshots/04-端到端/18-主管核准完成.png)

> **按「退回」會怎樣？**
> 單據回到申請人手上修改，改完可以重新送簽。
> 退回時務必填意見說明原因。

## 8. 財務簽核

### 8.1 為什麼會有這一關

因為折扣率 20% 超過了 15% 的門檻。流程的條件節點判斷後，
把單據導向財務加簽。

如果折扣率是 10%，這一關就會被跳過，流程直接往下走。

### 8.2 處理

登出後用 `finance@demo.local` 登入。

![財務收到待辦](screenshots/04-端到端/19-財務收到待辦.png)

節點名稱是「財務簽核」，與主管那關不同。

填意見後核准。

![財務核准完成](screenshots/04-端到端/20-財務核准完成.png)

## 10. 通知

流程走到每一關時，系統會寄 Email 給該關的簽核人。

信件內容包含：

```
標題：【待辦提醒】報價單 QT-2026-0042 待簽核

流程節點：主管簽核
單據編號：QT-2026-0042
剩餘時間：2 天

請至系統處理：http://localhost:3040/tasks
```

到期前也會依設定發提醒（見
[建立流程操作手冊](03_建立流程操作手冊.md) 第 8 節）。

## 常見問題

**送出後可以改嗎？**
不行。要先請簽核人退回，或自己取消後重建。

**我看不到別人的待辦，正常嗎？**
正常。待辦只有被指派的人看得到，這是刻意的設計。
管理員可以在流程監控看到全部（該功能尚未實作）。

**簽核人請假怎麼辦？**
可以在流程設定「逾時往上呈報」，時間到了自動轉給上一層主管。
見 [建立流程操作手冊](03_建立流程操作手冊.md) 第 8 節。

**為什麼我的單據狀態是「執行失敗」？**
通常是簽核人解析不到——角色沒有人、指定的人離職、部門沒設主管。
請管理員到 Temporal UI（http://localhost:8080）查看確切原因。

**折扣率為什麼填 20 會錯？**
系統用小數表示比率，20 會被當成 2000%。填 `0.2` 才是 20%。
