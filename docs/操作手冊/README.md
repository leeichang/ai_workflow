## 截圖如何產生

截圖不是手動截的，由 Playwright 腳本自動產生：

```bash
cd web
npx playwright test manual-01-form        # 02 手冊
npx playwright test manual-02-workflow    # 03 手冊
npx playwright test manual-03-permission  # 04 手冊
npx playwright test manual-04-endtoend    # 05 手冊
```

這樣做的理由：**UI 改版時腳本會失敗**，截圖不會默默過期留著騙人。
腳本裡每個截圖前都有嚴格斷言，元素找不到就直接失敗，
不會靜默跳過而產生「測試通過但少了幾張圖」的情況。

需要先啟動全部服務：

```bash
./start_service.sh
```
