# 測試報告編號規則

## 為什麼有 A / B 前綴

兩台機器平行開發，2026-09-19 同時產生了兩份 `14` 與兩份 `15`。
檔名衝突不像 migration 那樣會讓系統跑不起來，但交叉引用會指到錯的檔案。

**01～13 是分叉前的共同歷史，不加前綴也不改動。**
從 14 起依開發機分流：

| 前綴 | 機器 | 負責的線 |
|---|---|---|
| `A` | 這一台 | 組織基本資料與客戶系統同步（需求 07） |
| `B` | 另一台 | 模擬簽核、權限過濾、流程監控 |

編號各自遞增，互不干擾。

| 編號 | 主題 |
|---|---|
| B14 | 模擬簽核 |

## 新增報告時

用自己那條線的下一個編號。跨線引用時寫完整檔名，
不要只寫「見報告 15」——那在兩條線上各有一份。

同一個規則也適用 `server/migrations/`，見該目錄的 README。
