# 功能清單

- 日期：2026-09-14
- 階段定義：
  - **MVP** = 報價單場景 pilot 上線所需（Phase 0～5，約 14 週）
  - **MVP-P6** = 採購簽核場景（Phase 6，+3～4 週，共約 18 週）；引擎複用，僅增量
  - **P2** = AI 進場、其他資料來源、Designer 進階
  - **P3** = 規模化
  - **不做** = 第一年明確排除
- 每項標示來源：AI 彙整共識、使用者決議（D-xx）、假設（A-xx）、本文件補充。
